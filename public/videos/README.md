# Exercise video assets

Place short, muted, loop-friendly exercise clips here (for example `sole-rolls.mp4`).
Then add `videoSrc: "/videos/sole-rolls.mp4"` to the matching exercise object in `src/exercises.js`.
Optionally add a poster with `posterSrc: "/images/exercises/sole-rolls.jpg"`.

The workout UI automatically renders media when either field is present and falls back to instructions when media is missing.
